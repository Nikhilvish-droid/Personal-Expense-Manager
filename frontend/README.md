# FinNest

Personal finance tracker built for my IP mini-project. Lets you log expenses and income, see a dashboard summary, and check spending by category.

Frontend only right now — the data in `src/data/sampleData.js` is just mock data, there's no backend hooked up yet.

## Stack

React + Vite, react-router-dom for routing.

## Running it

```
npm install
npm run dev
```
